# Hotel Management System

Admin dashboard for a hotel, built with React, TypeScript, Vite and MUI (rooms, bookings, users, facilities, ads, charts, English and Arabic).

**Live demo:** https://omarbazeed.github.io/hotel-mangement-system/

The app talks to a hosted demo API (upskilling-egypt.com). Sign-in needs an account on that API.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
